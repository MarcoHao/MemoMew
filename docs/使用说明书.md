# MemoMew 使用说明书

## 一、产品简介

MemoMew 是你的**AI知识管家**——一个带可爱宠物助手的轻量级个人知识库。它帮你记录、整理、关联零碎的知识，并通过AI随时问答。

> 核心定位：**Windows便笺的AI增强版**

---

## 二、快速上手

### 1. 安装与启动

**macOS:**
1. 下载 `MemoMew-1.0.0.dmg`
2. 双击打开，将 MemoMew 拖入 Applications
3. 从启动台或 Applications 打开

**Windows:**
1. 下载 `MemoMew-1.0.0.exe`
2. 双击安装程序，按向导完成安装
3. 从开始菜单或桌面快捷方式打开

### 2. 首次配置

1. 打开应用后，点击左下角的 **⚙️ 设置**
2. 输入你的 **Kimi API Key**（在 [platform.moonshot.cn](https://platform.moonshot.cn) 免费获取）
3. 点击 **保存**

> 💡 Kimi API 有免费额度，日常使用几乎不产生费用

---

## 三、核心功能

### 📝 创建笔记

**方式一：直接输入**
1. 点击左侧「新建笔记」按钮
2. 输入标题和内容
3. 按 `Cmd+S` (Mac) / `Ctrl+S` (Win) 保存

**方式二：语音输入**
1. 点击编辑器工具栏的 🎤 麦克风按钮
2. 开始说话
3. 说完后再次点击停止，文字自动填入

**方式三：粘贴板捕获**
1. 复制任何内容到粘贴板
2. 按 `Cmd/Ctrl+Shift+O` 快速唤起 MemoMew
3. 直接粘贴到编辑器保存

### 🐱 与宠物互动

- 小橘猫会根据你的操作显示不同状态：
  - **待机**：轻轻摇晃尾巴
  - **聆听**：竖起耳朵听你说话
  - **思考**：处理你的请求
  - **说话**：播报AI回复
  - **开心**：完成操作后的庆祝

### 💬 AI 问答

1. 在右侧聊天面板输入问题
2. AI 会基于你的笔记内容回答
3. 小橘猫会用语音播报答案（可在设置中关闭）

**示例问题：**
- "我关于xxx的笔记里写了什么？"
- "总结一下我的所有笔记"
- "xxx和yyy之间有什么关系？"

### 🕸️ 知识图谱

1. 点击左下角的「知识图谱」按钮
2. 查看自动构建的实体关系网络
3. 拖拽节点调整布局
4. 点击节点查看详情

## 五、常见问题

**Q: 语音识别不工作？**
A: 请使用 Chrome 或 Edge 浏览器内核（Electron内置Chromium，支持良好）。确保已授权麦克风权限。

**Q: AI回答不准确？**
A: 确保已正确设置Kimi API Key。笔记越多、内容越详细，AI回答越准确。

**Q: 如何备份数据？**
A: 数据存储在本地SQLite数据库中。macOS位于 `~/Library/Application Support/MemoMew/`，Windows位于 `%APPDATA%/MemoMew/`。

## 六、系统要求

- **macOS**: 11.0 (Big Sur) 或更高
- **Windows**: Windows 10 或更高
